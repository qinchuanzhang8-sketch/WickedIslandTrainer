================================================
 荒岛修改器 —— Wicked Island 中文内置修改器 (WickedIslandTrainer) v1.1.0
 适配：Wicked Island 26.06.26 版（UE 5.6.1）
================================================

【这是什么】
一个内置的荒岛修改器：328 件物品全中文翻译 + 分类筛选，直接刷取到背包；
可修改人物数据（含疲劳/休息与饱腹系统）；可刷 27 种生物。按 Insert 呼出菜单。

【功能一览】

一、物品刷取（328 项全中文）
  1. 中文 / 拼音 / 英文 / ID 四种搜索方式（如 "木材" / "mucai" / "wood"）
  2. 15 类分类按钮（材料/食物/药水/防具/饰品/武器/弹药/工具/种植/
     驯养/战利品/繁衍/钥匙/其它），每个按钮显示该类数量
  3. 自定数量刷取（1-9999）、快速 x10 / x100、双击立即刷取
  4. 悬停查看中文物品描述；收藏后可置顶

二、刷怪
  27 种生物（狼/熊/野猪/鹿/狼人/熊人/野猪人/萨提尔/巨魔/食人魔/
  牛头人/翼龙/龙/梦魇/收割者/大恶魔/吸血鬼/人类 NPC/野人/奴隶 等），
  可设置数量 1-20，生成在角色身旁

三、人物数据（实时修改 + 锁定，锁定后持续保持）
  1. 生命 / 体力 / 饱食 / 水分 / 氧气：滑块修改 + 一键回满 + 锁定
  2. ★疲劳值（休息系统）：0 = 精力充沛，100 = 极度困倦
     · 拖动滑块直接修改疲劳值
     · 「精神百倍（睡饱）」：疲劳清零 + 清除疲惫状态 + 精力充沛增益
     · 「清除疲惫状态」：移除 疲惫/困倦/精疲力尽/神志不清 等负面状态
     · 「保持精力充沛」锁定：自动保持 0 疲劳 + 增益效果常驻
  3. ★上限 / 恢复 / 消耗设置：
     · 最大生命值 / 最大能量 / 最大饱腹 / 最大水分 / 最大氧气
     · 饱腹消耗速度（0 = 完全不饿）/ 水分消耗速度（0 = 完全不渴）
     · 生命回复 / 能量回复
  4. 负重上限可调到 5000 并锁定
  5. 一键满状态 / 全部锁定 / 解除全部锁定

【安装与使用】
  1. 完全退出游戏
  2. 把压缩包内容解压到 WickedIsland\Binaries\Win64\ 目录
     （覆盖提示选"全部是"）
  3. 双击「启动游戏（带修改器）.exe」启动游戏（必须用启动器，
     直接启动游戏本体不会加载修改器）
  4. 进入游戏后按 Insert 呼出/关闭修改器面板

【注意事项】
  1. 使用前建议手动存档一次
  2. 修改器只改内存数据，不修改游戏本体文件
  3. 全屏模式建议改为"无边框窗口"或"窗口化"运行
  4. 修改器对应 26.06.26 版游戏（UE5.6），游戏大更新后可能失效
  5. 遇到问题可查看 Binaries\Win64\wicked_mod_log.txt 日志
